# Project case study

## Academy Tech Coins — learning rewards for Academy-Tech.ir

### The opportunity

Online learners benefit from visible progress and useful reasons to return. A learning platform can bring together course progress, community participation, and hands-on practice, but rewards need to be understandable to learners and manageable by the site team.

### The concept

Academy Tech Coins adds a configurable virtual-currency layer to the learner experience. Eligible activities may include daily sign-in, course completion, comments or feedback on course and blog content, and using the site's code compiler. Site administrators choose which rules are enabled, how many coins they award, and applicable frequency limits. Learners can see their balance and redeem configured discounts at checkout.

### Experience principles

- **Clear:** Show the learner's balance and explain why a reward was earned or was not available.
- **Configurable:** Keep reward amounts, eligibility, and limits under administrator control.
- **Useful:** Make coins redeemable for a checkout discount rather than an abstract score alone.
- **Responsible:** Apply server-side eligibility checks and duplicate-award limits.

### Product value

- Supports habit formation with daily rewards.
- Recognizes learning completion and participation.
- Encourages practice through an integrated compiler activity.
- Gives administrators a flexible way to tune the reward program.
- Links engagement to a tangible purchasing benefit.

### Scope and status

This case study describes the product concept and public-facing feature set. Actual behavior depends on the plugin build installed on Academy-Tech.ir and the site's configuration. This repository does not claim that every described integration has been verified in production.

### Public portfolio note

The implementation is proprietary and is not distributed from this showcase. No source code, installation archive, site credentials, or learner records are included.
