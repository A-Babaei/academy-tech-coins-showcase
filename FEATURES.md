# Feature overview

## Learner experience

- Daily sign-in coin rewards, subject to administrator-defined limits.
- Rewards for supported learning milestones, including course completion.
- Configurable participation rewards for eligible comments or feedback on course and blog content.
- A configurable reward opportunity for using the site's code compiler.
- Account-area coin balance and reward feedback.
- Discount redemption through codes configured for checkout.

## Administrator controls

- Enable or disable individual earning rules.
- Set coin values and frequency limits for supported activities.
- Configure discount value, code format/prefix, validity, and checkout conditions where supported by the installed build and store setup.
- Review reward activity and user balances.

## Design intent

The settings should use clear labels and sensible defaults. Learners should be told what earned coins and whether a daily or activity limit has already been reached. Reward rules should be applied on the server and protected from duplicate submissions.

## Compatibility note

This overview is a product presentation, not a compatibility guarantee. Available rule types and checkout behavior depend on the plugin version, WordPress/WooCommerce setup, and site-specific integrations.
