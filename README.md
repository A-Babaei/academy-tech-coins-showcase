# Academy Tech Coins

**A learning rewards concept for [Academy-Tech.ir](https://academy-tech.ir): learn, participate, earn coins, and redeem discounts.**

[فارسی](#نسخه-فارسی)

Academy Tech Coins is a loyalty experience designed to encourage consistent learning and meaningful participation. Members can earn coins through configurable activities such as daily sign-in, course completion, discussion or feedback, and use of the site's code compiler. Coins can then be exchanged for discount codes usable at checkout.

> This repository is a public product and portfolio presentation. The proprietary plugin implementation and installable package are intentionally not included.

![Academy Tech Coins promotional poster](academy-tech-coins-poster.png)

## At a glance

- **For learners:** A visible coin balance, clear reward feedback, and practical discounts tied to learning activity.
- **For administrators:** Configurable earning rules, reward amounts and limits, discount settings, and activity visibility in one dashboard.
- **For the learning platform:** A framework for connecting course progress, community participation, and hands-on coding practice.

## Reward journey

1. A learner signs in, completes an eligible activity, or participates in a supported discussion.
2. The platform checks the configured rule and its earning limit.
3. Coins are credited to the learner and reflected in the account experience.
4. The learner redeems an available discount code during checkout.

## Project goals

- Make progress and participation feel visible and rewarding.
- Encourage daily learning habits without hiding the rules from learners.
- Let administrators adjust reward activities and values without changing code.
- Connect earned rewards to a useful checkout benefit.
- Keep crediting auditable and prevent repeated rewards beyond configured limits.
